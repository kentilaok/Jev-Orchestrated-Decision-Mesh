## 6. Findings worth knowing

1. **Codex model catalogue caching.** `codex debug models` first returned a stale cache without GPT-6 Luna and Sol; Codex refreshed it in the background. The provider now reports `cache_age_seconds`.
2. **Unverified Claude worker IDs.** The Claude worker family requests `claude-sonnet-5` and `claude-opus-5`. Whether Claude Code accepts these IDs has not been verified live. The console presets use `claude-sonnet-5-5` and similar.
3. **Fused-gate semantics.** The fused protocol changes option semantics (audit D-11), so fused-versus-legacy comparisons are confounded until that is addressed.
4. **Open audit defects.** D-08 (structural-only release checks), D-09 (unresolved items), D-12 (Jev near-ties), and D-13 (route choices near a coin flip) need owner decisions and live evaluation.

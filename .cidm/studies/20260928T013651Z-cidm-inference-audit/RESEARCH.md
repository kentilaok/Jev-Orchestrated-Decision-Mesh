## Distinctions this study verified locally

- **Jev returns typed choices, not prose.** Every saved Jev response is `{choice, probabilities, confidence}` (public: 74 calls [withheld: private project evidence]). Whoever writes the state capsule (host LLM or controller code) does the summarising. [withheld: private project evidence]
- **Route distribution ≠ success probability.** Jev's route probabilities are a distribution over labels. Confidence is a deterministic function of that distribution (R7/R9 rows). Neither was ever compared with outcomes. Byte-identical requests returned different distributions and, once, a different route (luna_low 0.55 vs sol_low 0.50).
- **No independence assumption.** No CIDM code multiplies Jev probabilities. The harness keeps each decision separate and combines them only through explicit option menus.
- **Cache semantics.** Caching reuses processing of supplied prefixes only. Hash or ID fields in Jev state (e.g. `accepted_predecessors: ["<file> <sha256>"]`) do not let Jev read the referenced content (AUDIT.md §3.6).
